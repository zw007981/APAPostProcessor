# 术语表

> 统一项目中的术语命名，消除同一概念在不同文档/代码里出现不同叫法导致的理解偏差（命名幻觉）。
> 引入一个新的领域概念时，请先检查这里是否已有约定命名；没有的话在此登记。

## 使用方式

- Dev Agent / Review Agent 在讨论、注释、命名代码时，优先使用本表中登记的术语。
- 发现代码里的叫法和本表不一致时，视为命名不一致问题，应在 Code Review 中指出。

## 术语列表

| 术语 | 代码中的对应命名 | 含义 | 备注 |
|---|---|---|---|
| （示例）位姿 | `Pose` | 车辆/机器人在某坐标系下的位置与朝向 | 示例条目，实际使用时请替换为项目真实术语 |
